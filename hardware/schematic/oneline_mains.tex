% ============================================================
% oneline_mains.tex — mains distribution after retrofit.
%
%   Motor branch:
%     DISC -> 30 A -> M1 (Size 1) -> OL heater -> motor
%
%   Control-supply branch (RETROFIT ADDITION):
%     tap after DISC -> 250 mA fuse -> isolated AC-DC PSU
%                    -> 5 V SELV rail to the ESP32 supervisor
%
% The control branch is tapped on the load side of the DISC and
% the line side of M1, so the ESP32 stays powered even when the
% coil drops. That is deliberate: it must stay alive to log the
% trip and hold the coil open until the operator acks.
%
% Regenerate with:  make oneline_mains.svg
% ============================================================
